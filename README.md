# ConcentrationCalculator-ClaudeCode
以下の指示で生成されたもの

水が X リットルのとき、濃度 Y% にするには、食材 Z グラムが必要かということを計算できるアプリを作ってほしい。X, Y, Z のうちどれかふたつが決まれば残りのひとつが決まるようにしてほしい。
出力は HTML ファイルで、ダウンロードできるようにしてほしい。
上記をブラウザで利用できるウェブアプリとして URL がわかれば動かせるようにする方法も教えてほしい。

公開 URL: https://bizhara.github.io/ConcentrationCalculator-ClaudeCode/
